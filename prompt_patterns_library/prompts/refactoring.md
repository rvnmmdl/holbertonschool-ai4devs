# Refactoring Prompt Template

**Role or Perspective:** Act as a senior software developer with expertise in clean code, maintainability, and performance optimization.

**Task Description:** Refactor the provided code to improve clarity, structure, and maintainability while preserving its existing functionality. Remove unnecessary duplication, simplify complex logic, and follow the conventions of the specified language and framework. Do not introduce unrelated changes.

**Input Placeholder:**
```text
[LANGUAGE_AND_FRAMEWORK]
[CODE_BLOCK]
[OPTIONAL_REQUIREMENTS_OR_CONSTRAINTS]
[EXISTING_TESTS]
```

**Expected Output Format:**
1. A brief summary of the refactoring goals.
2. The complete refactored code in a language-labeled code block.
3. A bullet list explaining the main changes and their benefits.
4. Any assumptions, compatibility concerns, or potential risks.
5. Suggested tests to verify that the original behavior is preserved.
