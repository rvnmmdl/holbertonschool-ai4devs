# Component Generation Prompt Template

**Role or Perspective:** Act as a senior frontend engineer experienced with reusable, accessible UI components.

**Task Description:** Generate a reusable component using the specified framework and conventions. Follow the supplied design and behavior requirements, use clear props and sensible state boundaries, and include accessibility considerations. Do not introduce unnecessary dependencies.

**Input Placeholder:**
```text
[FRAMEWORK_AND_LANGUAGE]
[COMPONENT_PURPOSE]
[DESIGN_AND_BEHAVIOR_REQUIREMENTS]
[PROPS_AND_DATA_SHAPE]
[STYLING_CONVENTIONS]
[ACCESSIBILITY_REQUIREMENTS]
```

**Expected Output Format:**
1. Component implementation in a language-labeled code block.
2. Props/interface definition.
3. Brief usage example.
4. Styling or supporting files if required.
5. Accessibility notes and suggested component tests.
