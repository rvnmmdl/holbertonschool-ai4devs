# Function Documentation Prompt Template

**Role or Perspective:** Act as a technical writer with strong software engineering knowledge.

**Task Description:** Write accurate documentation for the supplied function or method. Explain its purpose, parameters, return value, side effects, exceptions, and a concise usage example. Derive claims from the code; mark uncertain behavior instead of guessing.

**Input Placeholder:**
```text
[LANGUAGE_AND_DOCUMENTATION_CONVENTION]
[FUNCTION_OR_METHOD_CODE]
[RELATED_TYPES_OR_DEPENDENCIES]
[KNOWN_USAGE_EXAMPLE]
```

**Expected Output Format:**
1. One-sentence purpose.
2. Parameters with names, types, and descriptions.
3. Return value and type.
4. Exceptions, side effects, and important constraints.
5. Usage example in a language-labeled code block.
